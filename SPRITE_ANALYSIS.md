### Upgrade System (3 Levels)
Each spell has 3 levels with improvements:
- **Level 1:** Base spell
- **Level 2:** Reduced cooldown / increased range
- **Level 3:** More damage / more projectiles / larger area

**Example Upgrade Paths:**
1. **Pumpkin Shield**
   - L1: `pumpkin-shield.png` - Basic shield
   - L2/L3: `pumpkin-shield-upgrade.png` - Enhanced shield

2. **Pumpkin Smash**
   - L1: `pumpkin-smash.png` - Basic smash
   - L2/L3: `pumpkin-smash-upgrade.png` - Enhanced smash

## 📝 Usage Instructions

1. Open `sprite-converter.html` in your browser
2. For each sprite above:
   - Upload the sprite
   - Enter the columns and rows (inspect visually)
   - Convert to 1-row format
   - Download and replace the original file in the Sprites folder
   - Update this document with the frame count
3. Once all sprites are converted, we can create the spell system code
